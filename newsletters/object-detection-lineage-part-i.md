# The Two-Stage Detection Paradigm: From R-CNN to Faster R-CNN and Anchor-Based Region Proposals

**Date:** 2026-08-30
**Arc:** 1/2 — Object Detection Lineage

---

The curriculum so far has been shaped by tasks where the spatial question was already resolved: segmentation models predict a label for every pixel within a well-cropped volume, and image registration aligns two fields defined over the same spatial grid. Object detection dismantles that convenience. A detection model must locate arbitrary objects within an unconstrained scene and classify each one, simultaneously solving a regression problem — where is the object — and a recognition problem — what is the object. The history of how convolutional networks came to address both questions jointly, rather than through a haphazard assembly of independent modules, is instructive not only for practitioners building detection pipelines but for anyone who wants to understand how representational power and inductive structure interact in a trained system.

Before deep learning reshaped the field, detection pipelines relied on hand-engineered features such as HOG descriptors combined with sliding-window classifiers. The naive translation of that idea into a convolutional framework, running a classifier over every possible crop at every scale, is computationally intractable. The seminal insight in the R-CNN paper by Girshick and colleagues (2014) was to decouple the proposal stage from the classification stage. An external algorithm called selective search, which groups superpixels based on color, texture, and boundary cues, generates on the order of two thousand candidate regions per image. Each region is warped to a fixed 227×227 crop and passed through an AlexNet trained on ImageNet. The resulting 4096-dimensional feature vector is then classified by a set of class-specific linear SVMs, and a separate bounding box regressor adjusts the raw proposal coordinates toward the ground truth. R-CNN demonstrated that deep features extracted from pre-trained ImageNet models transferred powerfully to detection — a substantial finding at the time — but the system was cumbersome in practice. Each of the two thousand proposals required a full forward pass through the convolutional network, and because the three components (feature extractor, SVM classifiers, box regressor) were trained in separate stages, no single objective tied them together. Testing a single image took nearly fifty seconds.

The redesign introduced in Fast R-CNN (Girshick, 2015) followed a simple but consequential reordering. Instead of running the network separately on each cropped region, a single forward pass is performed over the entire image, producing a shared convolutional feature map. The candidate regions from selective search are then projected onto this feature map, and a technique called RoI pooling extracts a fixed-size representation from each projected region: the feature map within the region is divided into a fixed spatial grid, and max pooling is applied within each cell. This yields a constant-dimensional descriptor regardless of the original region's shape and size. The fixed-size RoI features are then fed into a small network that jointly predicts class probabilities via a softmax layer and bounding box offsets via a regression head. Crucially, the entire system — backbone feature extractor, RoI pooling, classifier, regressor — is trained end-to-end with a combined classification and localization loss. By sharing the convolutional computation across all region proposals, Fast R-CNN reduced test-time inference to under a second per image, with the remaining bottleneck being selective search itself, which still ran as an external, non-differentiable preprocessing step taking roughly two seconds.

Faster R-CNN (Ren, He, Girshick, and Sun, 2015) eliminates that bottleneck by replacing selective search with a Region Proposal Network, or RPN, that shares the convolutional backbone with the detection head. The RPN slides a small network over the convolutional feature map: at each spatial location, it predicts a set of objectness scores and bounding box regression offsets for a fixed collection of reference boxes called anchors. Anchors are predefined rectangles centered at the current feature map location, varying in scale and aspect ratio — a typical configuration uses three scales and three aspect ratios, yielding nine anchors per location. On a 40×60 feature map this generates roughly twenty thousand anchor candidates, each classified as foreground or background based on its intersection-over-union overlap with ground truth boxes during training, and each assigned a target box delta for regression. At test time, the RPN proposes the top-scoring candidates after suppressing redundant overlapping boxes with non-maximum suppression, typically yielding around three hundred region proposals per image. These proposals are then handed to the detection head exactly as in Fast R-CNN. Because the RPN and the detection head share the same feature pyramid, the extra computational cost of proposal generation is almost negligible — essentially a handful of convolutional layers over the already-computed feature map. The result was detection at roughly ten frames per second with accuracy substantially above prior published work on PASCAL VOC, and the paper laid the mechanical foundations that nearly every subsequent two-stage detector refined rather than replaced.

The anchor mechanism deserves careful attention because it encodes a specific inductive structure that shaped the entire generation of detectors that followed. By defining a finite set of reference boxes at each feature location, the model converts an open-ended search problem into a closed regression problem: rather than freely predicting arbitrary coordinates, each detection head predicts a bounded offset relative to a known anchor. This is translation equivariant in the sense that an anchor at location A is structurally identical to an anchor at location B; the same set of weights handles both. The multi-scale design — several anchor sizes per location — allows a single feature map resolution to handle objects across a large range of sizes without explicitly building a multi-scale feature pyramid, though subsequent work (Feature Pyramid Networks) would show that maintaining representation quality across scales required more than anchor diversity alone. The two-stage structure itself, generating a manageable set of high-recall proposals and then refining them, provides an important inductive prior: stage one acts as a coarse filter that trades precision for recall, guaranteeing that nearly all true objects appear in the proposal set, while stage two specializes in precise classification and localization within that pruned candidate pool. This decomposition proved remarkably durable and will continue into the next session, where one-stage detectors challenge it by removing the proposal stage entirely and where DETR recasts detection as a set-prediction problem that eliminates anchors altogether.
